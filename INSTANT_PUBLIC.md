## ❓ QUICK TROUBLESHOOTING

**"npm not found"**
→ Install Node.js from nodejs.org

**"python not found"**
→ Install Python from python.org

**"Port 3000 in use"**
→ Kill process: `lsof -i :3000` (Mac/Linux) or use different port

**"URL not working"**
→ Check all 3 terminals are running
→ Wait 5 seconds for connection

**"Can't reach from mobile"**
→ URL should work anywhere
→ Check WiFi/network connection
→ Try with different phone
